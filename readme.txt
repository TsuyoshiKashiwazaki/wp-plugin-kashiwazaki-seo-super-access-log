訪問者追跡、ボット検出、CSV入出力、チャート表示、セキュリティ機能を備えたWordPressアクセスログプラグイン

== 説明 ==

Kashiwazaki SEO Super Access Logは、サイトのトラフィックを詳細に監視したいWordPress管理者のための強力で包括的なツールです。単純なアクセスログ記録を超えて、分析、セキュリティ、追跡、データ可視化、エンタープライズグレードのパフォーマンス最適化のための高度な機能を提供します。

**主要機能:**

*   **詳細なアクセスログ記録:** IPアドレス、User-Agent、リファラー、リクエストURI、ステータスコードなど、すべてのリクエストの重要な情報を記録
*   **Cookie による訪問者追跡:** 各ユーザーに一意の訪問者IDを割り当て、新規訪問者とリピーター、ページ遷移を追跡
*   **国コード推定:** IPアドレスに基づいて訪問者の国を自動推定（オプション機能、設定で有効化可能）
*   **アクセス推移チャート:** Search Console風の美しいラインチャートで日次アクセスパターンを表示
*   **期間プリセット:** 24時間、1週間、1ヶ月、3ヶ月、6ヶ月、12ヶ月の期間プリセットまたはカスタム日付範囲で素早くフィルタリング
*   **静的ページトラッキング:** 簡単なJavaScriptスニペットとREST APIを使用して、静的HTMLページ（WordPress外）の訪問を追跡
*   **強力なフィルタリングとソート:** あらゆるデータポイント（IP、URI、User-Agent、国、ステータスなど）で簡単にログをフィルタリング・ソート
*   **高度なパフォーマンス最適化:** データベースインデックス、クエリ最適化、自動クリーンアップ、大規模データセット向けのインテリジェントなチャート管理
*   **柔軟なチャート設定:** サーバー能力に応じたパフォーマンスしきい値のカスタマイズが可能
*   **訪問者ブロック:** 訪問者IDまたはUser-Agentパターンで特定の訪問者をブロックし、不要なアクセスを防止
*   **疑わしいアクティビティ検出:** カスタマイズ可能なパターンに基づいて、潜在的に悪意のあるリクエストを自動的にフラグ付け
*   **User-Agent空フィルタリング:** User-Agentがないリクエスト（通常は脆弱性スキャナー）を自動的に除外、オプションで403ブロック可能
*   **CSV エクスポート/インポート:** 大規模データセット向けの非同期処理でCSVエクスポート、既存CSVファイルのインポートでデータ移行やバックアップ復元が可能
*   **エンタープライズ対応:** 最適化されたデータベースクエリとメモリ管理で数百万のログエントリを効率的に処理

== インストール ==

1. プラグインファイルを `/wp-content/plugins/kashiwazaki-seo-super-access-log` ディレクトリにアップロードするか、WordPressプラグイン画面から直接インストール
2. WordPressの「プラグイン」メニューからプラグインを有効化
3. WordPressダッシュボードの「Kashiwazaki SEO Access Log」メニューからログを表示し、設定を構成
4. アクセス推移チャートがデフォルトで表示されます（デフォルト期間: 1ヶ月）
5. 期間プリセットまたはカスタム日付範囲を使用して異なる期間を分析
6. サーバー仕様に基づいて「設定」タブでパフォーマンス設定を構成

== よくある質問 ==

= このプラグインはサイトのパフォーマンスに影響しますか？ =
ログ記録処理は `shutdown` フックに接続されており、ページがユーザーに送信された後に実行されるため、読み込み時間への影響を最小限に抑えます。プラグインにはデータベースインデックス、クエリ最適化、インテリジェントなチャート管理などの高度なパフォーマンス最適化が含まれています。非常に大規模なデータセットの場合、パフォーマンスを維持するためにチャートを自動的に無効にできます。

= パフォーマンス最適化はどのように機能しますか？ =
プラグインには、高速クエリのためのデータベースインデックス、古いログの自動クリーンアップ、大規模データセット用のメモリ管理、構成可能なチャートしきい値が含まれています。数百万のログエントリを効率的に処理できます。

= チャートのパフォーマンス設定をカスタマイズできますか？ =
はい！サーバー能力に基づいてパフォーマンスを最適化するためのチャート表示制限を設定できます。50,000から無制限までのオプション、またはカスタム値を設定可能です。

= アクセス推移チャートはどのように機能しますか？ =
推移チャートは、選択した期間の日次アクセス数を美しいライングラフで表示します。期間の前半と後半を比較してトレンドを自動計算し、トラフィックが増加、減少、または安定しているかを示します。曜日インジケーターは週次パターンの識別に役立ちます。

= トレンドチャートのデフォルト期間を変更できますか？ =
はい！プラグインはデフォルトで過去1ヶ月を表示しますが、24時間、1週間、3ヶ月、6ヶ月、12ヶ月に簡単に切り替えたり、期間プリセットドロップダウンを使用してカスタム日付範囲を設定したりできます。

= デフォルトで表示されるログ数は？ =
ログテーブルは、読み込みを高速化するためにデフォルトでページあたり10件のログを表示します。ログテーブルの上のドロップダウンセレクターを使用して、ページあたり30、50、または100件のログに変更できます。

= 訪問者/User-Agentブロックはどのように機能しますか？ =
リクエストが来ると、プラグインは設定で構成したブロックリストに対して訪問者のCookie IDとUser-Agent文字列をチェックします。一致が見つかった場合、プラグインは実行を停止し、503 Service Unavailableエラーページを提供してサイトへのアクセスを防ぎます。

= 設定はどこにありますか？ =
「Kashiwazaki SEO Access Log」メニューに移動します。設定パネルはそのページの「設定」タブにあります。

= WordPress以外のページを追跡できますか？ =
はい。設定で「静的ページトラッキング」機能を有効にし、提供されるJavaScriptスニペットを静的HTMLファイルにコピーします。これにより、トラッキングデータがWordPressサイトのREST APIに送信されます。

= 自動クリーンアップはどのように機能しますか？ =
プラグインは、構成可能な保持期間（デフォルト: 90日）に基づいて古いログを自動的に削除できます。これはWP-Cronを介して毎日実行され、最適なデータベースパフォーマンスの維持に役立ちます。

= ログデータは安全ですか？ =
ログデータはWordPressデータベース内のカスタムテーブルに保存されます。ログビューアへのアクセスは `manage_options` 権限を持つユーザー（通常は管理者）に制限されています。プラグインにはSQLインジェクションやその他の攻撃に対するセキュリティ対策が含まれています。
