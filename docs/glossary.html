用語集

このマニュアルと管理画面に出てくる用語を、五十音順ではなく関連する順にまとめました。

アクセスと訪問者

用語意味
ログ1 件のアクセスの記録。日時・ページ・IP アドレス・ブラウザなどを含みます。
訪問者 ID訪問者を見分けるために、プラグインがランダムに作る ID。訪問者のブラウザの Cookie に保存します。
Cookie（クッキー）サイトが訪問者のブラウザに保存する小さなデータ。このプラグインは訪問者 ID を保存します。
ユニーク訪問者重複を除いた訪問者の数。訪問者 ID で数え、ID がない記録は IP アドレスで数えます。
訪問タイプ新規・リピーター・ページ遷移・不明の 4 つ。→ 訪問タイプの決まり方
新規訪問の記録（Cookie）がない訪問。初めての訪問や、Cookie の期限が切れた訪問です。
リピーターCookie があり、ほかのサイトから、または直接来た訪問。
ページ遷移Cookie があり、このサイトのページから来た訪問（サイトの中の移動）。
ソース記録の出どころ。WordPress のページ・静的ページ・CSV からの取り込み（Import）。

リクエストの情報

用語意味
IP アドレスインターネット上の住所にあたる番号。アクセス元のネットワークを表します。
User-Agent（ユーザーエージェント）ブラウザやボットが名乗る名前。ブラウザの種類・OS・ボットの名前などが入ります。
リファラー（参照元）そのページに来る直前に見ていたページの URL。
リクエストパス開かれたページの、ドメインより後ろの部分（例: /blog/article/）。
メソッドリクエストの方式。ページを見るときは GET、フォームを送るときは POST など。
ステータス（ステータスコード）サーバーの応答の状態を表す番号。200 は成功、404 は見つからない、500 番台はサーバーのエラー。
国コード国を表す 2 文字のコード（JP、US など）。LAN は社内などのネットワーク。

判定と防御

用語意味
ボット（クローラー）人ではなくプログラムが行うアクセス。検索エンジン・SEO ツール・AI のクローラーなど。
ボット検出パターンUser-Agent からボットを見分けるための、文字のパターン（正規表現）。
正規表現文字のパターンを表す書き方。| は「または」を意味します。
疑わしいアクセスURL や User-Agent に、攻撃の試みに多い文字列（疑わしいキーワード）を含むアクセス。
除外（ログ除外URIパターン）記録しないページの指定。アクセス自体は許可します。
ブロックアクセス自体を拒否すること。訪問者 ID・User-Agent・User-Agent が空、の 3 つの方法があります。

データと管理

用語意味
軽量な形式（軽量化）1.0.1 からのログの保存形式。容量が小さく、表示が速くなります。以前の形式から自動で移し替えます。
集計合計・グラフを速く表示するため、裏で自動的に作っている 1 時間ごとのまとめ。
キャッシュ一度作った表示用のデータを、しばらく保存して使い回すこと。
自動クリーンアップ保存期間を過ぎたログを、1 日 1 回自動で削除する機能。
統計情報の更新データベースが検索のしかたを決めるための情報を最新にすること。
断片化削除などで生じた、データベースの中の空き領域の割合。
インデックス（索引）データベースの検索を速くするための索引。
CSV項目をカンマで区切った文字のファイル。表計算ソフトで開けます。
エクスポート / インポートログをファイルに書き出すこと / ファイルからログを取り込むこと。
WP-CronWordPress の予約実行のしくみ。サイトへのアクセスをきっかけに、予定した処理を動かします。
表示タイムゾーンメインタブで時刻を表示するときの時間帯。初期値は UTC（世界標準時）。
静的ページWordPress を使わず、HTML ファイルだけで作ったページ。
